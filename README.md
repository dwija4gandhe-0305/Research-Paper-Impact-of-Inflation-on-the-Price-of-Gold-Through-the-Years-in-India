# Research-Paper-Impact-of-Inflation-on-the-Price-of-Gold-Through-the-Years-in-India
Conducted an ARDL-based study (2000–2023) examining the long-run relationship between inflation, exchange rates, GDP per capita, and gold prices in India, finding evidence supporting gold as an inflation hedge and safe-haven asset.
